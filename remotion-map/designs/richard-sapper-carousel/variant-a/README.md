# Richard Sapper 카드뉴스 샘플

리처드 사퍼의 작업 방식을 6장 세로형 릴스로 풀어낸 비공개 웹 미리보기입니다. 각 장은 검은 배경에서 상단 주제와 하단 `미니멀 모으기 1/100` 자막을 고정하고, 낮은 중앙 미디어 프레임 안에서 작품 이미지컷과 격자 설명컷을 교차합니다. 설명컷은 흰 격자 위에 관계를 보여주는 도형 2~3개와 짧은 문장 하나만 둡니다.

- `index.html`: 좌우로 넘겨 보는 9:16 웹뷰
- `richard-sapper-carousel.pen`: 1080×1920 릴스 프레임 6장. 웹뷰의 설명컷과 같은 도형·문장 구조를 담습니다.
- `tizio.jpg`, `ts502.jpg`: 작품 이미지컷 원본. 출처는 Made In Design과 Brionvega입니다.
- `ts502-dark.png`: TS 502의 중앙 릴스 프레임용 어두운 배경 파생 컷입니다. 원본 제품 구성을 유지하면서 흰 여백을 제거했습니다.
- `sapper-still-life.png`: ThinkPad 설명컷에 쓰인 생성 정물입니다. 실제 제품·로고의 복제물이 아닙니다.

## 릴스 양식 기준 파일

[`richard-sapper-carousel.pen`](./richard-sapper-carousel.pen)을 **미니멀 모으기 릴스의 기준 편집 파일**로 사용합니다. 새 주제로 만들 때는 이 파일을 복제한 뒤, 아래 요소는 유지하고 중앙 콘텐츠만 교체합니다.

- 1080×1920 프레임과 검은 상·하단 여백
- 상단 가운데 정렬 두 줄 제목, 하단 가운데 정렬 `미니멀 모으기 1/100`
- 낮은 중앙 미디어 영역(이미지컷 또는 설명컷)
- 설명컷은 흰 격자 위의 도형 2~3개·관계선/화살표·짧은 문장 하나
- 마지막 장은 장식선 없이 `미니멀한 발견을 제보해주세요`와 짧은 DM 제보·문의 보조문구만 둡니다.

웹에서 구성과 순서를 확인할 때는 [`index.html`](./index.html)을 사용합니다. 이 HTML과 `.pen`은 같은 6장 구조·문구를 기준으로 함께 수정합니다.

## A안 훅

`디자인은 왜 / 조용해야 할까?`는 사퍼의 작업 방식을 차분하게 여는 기준안입니다. 대비용 B안은 [`variant-b/`](./variant-b/)에 있습니다.

사실 근거는 Infinity 원격 `research-richard-sapper-deadline-20260917`의 최종 브리프(MoMA, IBM, Alessi, Richard Sapper Design)입니다. 공개 게시나 계정 업로드는 하지 않았습니다.

# Remotion map and explainer clips

This package contains short-form map, overlay, and explanatory clips made with Remotion.

## YouTube chart explainer

`YoutubeChartExplainer` is a 3-second, vertical (1080×1920, 30fps) explanatory cut: headline first, chart line drawing second, closing takeaway last.

```bash
npm run render:youtube-chart
```

The rendered file is written to `out/youtube-chart-explainer.mp4`.
